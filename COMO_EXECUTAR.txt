TechBairro 3.3.3

Requisitos
    - Python 3.12 (testado com Python 3.12.0 no Visual Studio Code)
    - Nenhuma biblioteca extra: usa apenas tkinter, os, sqlite3 e re, que já vêm com o Python
    - No Linux pode ser preciso instalar o Tkinter: sudo apt install python 3-tk

Como executar
    1. Extraia o arquivo TechBairro-3.3.3.zip
    2. Abra um terminal dentro da pasta TechBairro-3.3.3.
    3. Execute: python main.py

Dados
    - Na primeira execução, o arquivo do banco de dados é criado vazio na mesma pasta.
    - Faça cópias desse arquivo para não perder os clientes cadastrados.

Histórico do código
    - O projeto usa Git. Para ver o histórico, rode na pasta do projeto: git log --oneline
